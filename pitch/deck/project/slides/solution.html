Five parts working together. On top, the interface: a web app with the chat, the slide preview, the sources and the settings. Left, scraping and indexing, offline and without a language model: we crawl the websites of UniBE, ARTORG and the Diabetes Center Berne, clean them, split them into passages, embed them with BGE-M3 and keep the search index locally. A new website is one start URL on the Sources page. In the middle, the RAG part, sitting between the index and Apertus: search by meaning, with hypothetical passages written in the words of the sources (HyDE), and read the best pages in full. Right, Apertus 70B, the Swiss open model. As orchestrator it gets every chat message and calls the retrieval tools; with what comes back it composes the items, with quotes, so it only writes from what it retrieved. Then plain code checks every fact against its page, and the export renders the slides with Typst in the Kanton Bern design, shown next to the chat and downloadable as PDF or PowerPoint.
