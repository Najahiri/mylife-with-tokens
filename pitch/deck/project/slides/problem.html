01 · THE PROBLEM

A company with a need.
Research that could meet it.

Between them there is no direct interface. Matching a company to the right research groups, infrastructure and people means knowing every institute in Bern, and searching site by site.

A real run, sped up: 95 seconds from question to slides.

WHY IT IS HARD

1

Scattered and convoluted

41 websites, 18,332 pages, three languages, every site structured differently.

2

Contained run time

An answer should take minutes, not hours: the agent works in a capped number of steps.

3

Sovereignty

Apertus, the open Swiss model, and a search database we build and run ourselves, from sources we choose.

The problem: a company with a concrete need on one side, Bern’s research on the other, and no interface between them. Today, matching them means knowing every institute and searching site by site. On the right, a real run of RAGlette, sped up: you name the company, the agent searches, reads the best pages, adds items that pass the check, and the slides build up next to the chat. The whole run took 95 seconds. Why is this hard? One: the sources are scattered and convoluted, 41 websites, 18,332 pages, three languages, no common structure. Two: we wanted to keep the run time contained. An answer should take minutes, not hours, so the agent works in a capped number of steps. Three: sovereignty. The process runs on Apertus, the open Swiss model, and on a search database we build and run ourselves, from public sources we choose.
